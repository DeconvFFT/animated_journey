# Animated Journey

An animated film of one life, from childhood to today, made by one maker with an AI team: Claude as orchestrator, a Fable advisor reviewing every step, Sonnet researchers and implementers, and Haiku scribes.

- `CHARTER.md`: what we're making, principles, team, review rubric
- `ROADMAP.md`: the plan to the premiere (coming out of the Learn phase)
- `playbooks/`: guides for the maker
- `research/`: sourced research notes
- `reviews/`: Fable advisor reviews
- `.claude/`: the AI team's agent definitions and skills

Status: **Learn phase**. No production code or personal media yet.

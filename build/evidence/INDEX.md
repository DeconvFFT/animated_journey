How to read this. Result is what the area's `run_tests.sh --quick` did: PASS (exit 0), FAIL (non-zero), TIMEOUT (killed at the limit; also a FAIL), NOT LANDED (`tests/<area>/run_tests.sh` does not exist yet; not a failure). The five count columns come from the `lj-evidence/1` envelopes found under the entry's evidence folder (build plan 4.2), one per package and test, the newest winning; a NOT LANDED entry can still show envelopes that were written before its tests existed. Refreshed says whether any of those envelopes was written during this run: `no` means the counts are older evidence (for example an area whose --quick run writes only a text log), `-` means no envelope exists. UNVERIFIED means a claim that needs the maker's Windows PC; it is never counted as PASS. `Lowest avail_mb_min` is the smallest free-disk figure any envelope of the entry recorded (MB); below the hard floor it is marked LOW. Every link above points to a file or folder that exists when this page is written.

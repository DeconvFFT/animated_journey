## 6. Nudges (at most six, concrete)

1. **`scripts/decisions_to_csv.py` line 64, `ROW_RE`:** `r"^\|\s*([DWOS])-([0-9]{2,3})\b([^|]*)\|"`. In `parse_register`, keep the stripped group 3 (for example `absorbs O-40`, parentheses removed) as `annotation` on the raw row, and in `build_rows` prepend it to `note` (`"absorbs O-40; " + note`) so the text is not lost. Add a near-miss guard in the same loop: a line matching `^\|\s*[DWOS]-[0-9]` that does **not** match `ROW_RE` raises `ValueError("line %d: looks like a register row but does not parse")` so a row can never vanish silently again.
2. **`scripts/ops_lint.py` line 66, `REGISTER_ROW_RE`,** and **`tests/ops/run_checks.py` lines 147, 159, 283:** the same `\b[^|]*` widening (one shared pattern string in `decisions_to_csv.py`, imported by `ops_lint` through `load_sibling`, is better than five copies). Add a negative test `decisions_annotated_id` modelled on `decisions_three_digit_id`: a register copy with `| O-NN (absorbs O-MM) |` (IDs from `next_id`) reaches the CSV with the annotation in `note`, `ops_lint`'s `cited_id` accepts O-NN in a GATHER copy, and a line `| O-NN|broken` makes `--write` exit 2.
3. **Regenerate and re-report after nudges 1 and 2:** `python3 -I scripts/decisions_to_csv.py --write ops/decisions.csv` (expect `248 rows (D 31, W 79, O 73, S 65)` against the 07:10 register; say the register, not a number, sets it), `bash tests/ops/run_tests.sh --all` to 0 FAIL, then rewrite `build/reports/WP-02.md` §1 (counts), §3 and the "Changes after review" table so they equal the new `summary.json`; one sentence that the register moved at 07:10, after the 07:08 report.
4. **`ops/GATHER.md` A1 rows O-07 and O-08:** match the register's current wording. O-07: two candidates (the tune she sang to you; the song the women sang at a birth or wedding), a closed-mouth and an open-vowel take of each, uncleaned, into `originals/` (W-65), IDs `HUM-01` to `HUM-04` or `HUM-01a/b`; O-08: add "is there a hichko, does she sit in it every evening, at what hour, did it travel with her" (W-67). Keep `HUM-01` present so `check_gather`'s required list still passes, and re-run `howto_gather_content`.
5. **`scripts/ops_lint.py` `Patterns.mask`:** honour `mask.cap` from the pattern file (`self.cap = int(mask.get("cap", 8))`; `hit[:keep] + fill * min(len(hit) - keep, cap)`), so `ops_lint` and `public_lint` print the same mask and a hit's length no longer leaks; update the `lint_bad_note` needles (`ja********`).

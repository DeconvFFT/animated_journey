## 5. Nudges (carry forward to the next implementor round; none blocks approval)

1. `pipeline/roundtrip/validate_otio.py`, `clips_present` (line 229): count only clips with `it.get("enabled", True)` on tracks with `t.get("enabled", True)`, so a Video track of disabled clips, or a disabled Video track, fails `no_clips` (B1; r2 nudge 1). Plant `all_clips_disabled` and `video_track_disabled` in `plant.OTIO_DEFECTS`.
2. `pipeline/roundtrip/validate_otio.py`, after `rate_24` (line 174): add a `whole_frames` check that FAILs `time_not_whole_frame` when any RationalTime `value` is not a whole number (`float(v).is_integer()`), so a 120.5-frame clip or a 12.5-frame offset is refused (B2). Plant `fractional_frames`.
3. `pipeline/roundtrip/validate_otio.py`, markers section (line 279): add `markers_in_range`, FAIL `marker_outside_range`, for a clip marker whose `marked_range.start_time` is outside its clip's `source_range` and a stack or track marker beyond the track length (B3; the emitter already enforces this for a spec). Plant `marker_outside_clip`.
4. `pipeline/roundtrip/validate_otio.py`, line 201: make the drive-letter test `^[A-Za-z]:` (no slash), the same as `emit_otio.is_rel`, so `C:media/x.png` is `target_url_absolute` even with `--no-media-check` (B4).
5. `pipeline/roundtrip/emit_otio.py`, `_make_media` (lines 296 to 304): generate each shot's card at that shot's own `source_size` (`tuple(s["source_size"]) if s.get("source_size") else (2880, 1620)`) instead of one size for all, so a mixed-size test spec gives media that matches the spec and the emitted file passes its own validator (B5). Add a two-size spec to `otio.emit_refusals`'s neighbour tests.
6. `pipeline/roundtrip/validate_ora.py`, `whole()` (line 139): use `re.match(r"^-?[0-9]+$", str(v))` (ASCII digits, no `strip()`), and check `opacity` with `re.match(r"^(0|1|0?\.[0-9]+|1\.0+)$", ...)` or at least refuse exponents, so `x="٣"`, `x=" 200 "` and `opacity="1e0"` fail `layer_value_invalid` (B6; r2 nudge 2). And `pipeline/roundtrip/validate_otio.py`, docstring line 5: write `<scratch>/venv-otio/bin/python` (B7; r2 nudge 3).

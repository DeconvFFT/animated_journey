## 3. Nudges (none blocking; at most six)

Either give `hygiene` its own limit as `win_kit2` has (90 s), or trim the quick group: the committed re-run, the `--staged` run of every case and the eight-list loop could run only in `--all`. One of the two before the week-3 quick passes start.
2. **`tests/hygiene/test_lint.py`, section 5 comment.** It says "or a symbolic link, fails all three", but no case plants a link. My case A shows why it matters: a link that is force-added fails on the index test ("the index copy is not a PNG image"), so the "working-tree path is a symbolic link" branch of `force_added_check` is reached only when the file is replaced by a link after the add and not re-added. Plant that case (add the card, then `os.symlink` over it, do not re-add) or drop the words.
3. **`allow_binary_note` in `scripts/public_lint.config.json`** still reads "at most three review images may be force-added (CLAUDE.md, Git)"; `CLAUDE.md` says only "Generated, non-personal images can be added with `git add -f` after review", and nothing counts the list's length. In the next housekeeping pass, point the note at `force_added_ok` instead (the implementor's section 5 item 5).
4. **Two config messages.** A listed path with a trailing space or an upper-case `.PNG` is refused as "not a .png path"; say "(lower-case `.png`, no leading or trailing space)" in that message, so the orchestrator who mistypes an entry sees the cause. A `\` is refused as "a glob or pattern character"; add "or a backslash: use `/`" since the entries will be typed on a Windows PC one day. Wording only.
5. **`public_lint.py --all` and the three-checks sentence.** The whole-tree audit returns before the ignored-tracked loop, so `--all` says nothing about a force-added file (pre-existing, not this package's change; `repo.gitignore_coverage` and the diff mode cover it). 6. **`tests/hygiene/README.md`** says the quick runner takes "about 45 s" and `run_tests.sh` says the same; measured 40 s here. Fine as written; if nudge 1 trims the group, bring both figures down in the same edit.

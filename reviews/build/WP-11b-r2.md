## 3. Tests of my own, designed to break it

**A. The static `lj.ps1` scan, wider plant (34 one-line forms appended to a copy).** Caught 10, **missed 24**: the Windows PowerShell 5.1 aliases of the downloading and writing cmdlets (`iwr`, `irm`, `curl`, `wget`, `ni`, `ac`, `clc`, `cpi`, `sp`, `rp`, `tee`, `epcsv`), `Clear-RecycleBin`, the external commands `cmd /c del`, `cmd /c rd /s /q`, `robocopy /MIR`, `reg delete`, `attrib`, `New-Object IO.StreamWriter`, a cmdlet inside a subexpression of a double-quoted string (`"cleaning $(Remove-Item $x -Recurse)"`, which `strip_ps` removes with the string although a scan could see it), `& $git commit` (a variable command: that one is the `tests/win_lj/` class), and the git verbs `worktree remove`, `branch -D`, `submodule update`. Zero false positives on nine harmless lines (`-gt`, `-ge`, `-shr`, a hash key `rd`, `'rd*'` in a `-like`, `-replace '>'`). The real `win/lj.ps1` uses none of the missed forms (grep), so the live PASS stands and WP-01b's behavioural tests remain the proof of behaviour; the test's text "no ... downloading command" and "alias" are wider than what the oracle sees. Nudge 1.

**B. The readiness parser.** A third status table appended with the header `| # | Item | Needs Windows | **Status** | ...` (or `| No. | ...`) is not recognised as a status table, so a `C20 | yes | PASS (container)` row inside it is **silently ignored**. The two real tables cannot vanish this way without the M1 to M8 and `lj.ps1 close` checks firing, so the live result stands; a future third table could hide a row. Nudge 2.

**C. The register regex.** W-63 rewritten with a parenthetical inside the PH2 clause fails closed (good); `4.0 Mb/s` reads as 4.0 (good); the row without W-18 fails closed (control). The oracle is tied to the row's wording, which is the price of reading the register instead of typing figures; the fail-closed message names the shape it reads, so a future scribe can re-tie it in one line.

**D. The disk floors and the `--only` isolation**: both robust (section 2, rows 3 and 8).

**E. The owner-path discipline and redaction**: nothing outside the owner paths carries a WP-11b edit; the evidence is relative-path only; `build/evidence/pc/` holds the README and nothing else; no fixture GPU, CPU or driver string anywhere under `build/evidence/` (the suite's own check, and I read the folder).

## 3. Tests of my own, designed to break it

1. **Every folder label at once, end to end.** A fake `ffmpeg` that swallows the frames and then fails with an error line naming a path under a fake home (`HOME=<scratch>/home_<invented>`), the output `.part.mp4` and the work folder's log: `kenburns_24: environment problem: ffmpeg failed while making the movie (exit 1): Error opening output <home>/Pictures/secret_qx.jpg and <out>/x.mp4.part.mp4 and <work>/ffmpeg_main.log: Permission denied`, exit 3, the output folder empty afterwards. `pc_helpers.py clip` with the same fake: `<out>` masked, exit 3. Good: the unit test's promise holds through the real plumbing.
2. **Archive scripts under a profile folder.** `archive_init.ps1 -Root <fake home>/lj/standin -Count 2` and `archive_verify.ps1` with `HOME`/`USERPROFILE` set to a folder whose name is an invented name: `folder: %USERPROFILE%/lj/standin`, `files written (under %USERPROFILE%/lj/standin): ...`, `RESULT: OK`; a grep for the invented name over all output: 0 hits. The second `archive_init` on the same folder changes nothing.
3. **A Python library warning (the residual).** Pillow warns (does not refuse) for a still between 1x and 2x its 89-megapixel limit, and Python's default warning format prints the warning's *source file*: with the limit lowered to 4 MP against the 6 MP test still, the tool's stderr carries `/usr/local/lib/python3.13/dist-packages/PIL/Image.py:3578: DecompressionBombWarning: Image size (6000000 pixels) exceeds limit ...`. On the PC with the README's `pip install --user`, that path is `C:\Users\<name>\AppData\Roaming\Python\...\PIL\Image.py`, and the wrapper shows the tool's stderr live. Trigger: a still over about 89 megapixels (a 1200 ppi A4 scan, a 100 MP camera, a stitched panorama); the maker's Exercise 2 stills are far smaller, so this is rare, but it is the same class as the r1 issue and is nudge 1. `numpy` warnings (`RuntimeWarning`) would print the same way; none fire on the normal path (checked: the self-test and a two-still run print none).
4. **Odd option values.** `--seconds nan` and `inf` end in the one `unexpected error (...)` line (exit 3; the report already says a usage refusal would be better, nudge 2); `--seconds abc` is an argparse refusal naming only `kenburns_24.py`.

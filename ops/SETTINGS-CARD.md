**How to read it.** Each row is one decision, with what it means in plain words, the value we propose, the register ID it comes from, a command that proves a finished file meets it, and what changes if you change your mind. Values marked **proposed (J)** are our judgement and can still move before you sign. **UNVERIFIED:** the commands were tried on the cloud machine (Linux, ffmpeg 6.1.1); on your Windows PC they are UNVERIFIED until the PC check and the colour-patch runner have been run there (W-28). `FILE` stands for the finished video you are checking.
